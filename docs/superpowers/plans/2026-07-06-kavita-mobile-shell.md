# Kavita Mobile Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a first-iteration iOS/Android Capacitor app that opens a configured Kavita server URL in a full-screen app shell without mobile browser chrome.

**Architecture:** Use a minimal Vite + TypeScript web app as the bundled Capacitor entry point. The web app validates the configured Kavita URL, shows a small launch/retry screen, and navigates the WebView to Kavita; Capacitor packages that entry point into iOS and Android native projects.

**Tech Stack:** Node.js, npm, Vite, TypeScript, Vitest, jsdom, Capacitor iOS, Capacitor Android.

---

## File Structure

- Create: `package.json` - npm scripts and dependencies for Vite, Vitest, TypeScript, and Capacitor.
- Create: `index.html` - Vite HTML entry point.
- Create: `src/main.ts` - browser bootstrap that renders the launch UI and navigates to Kavita.
- Create: `src/kavita-url.ts` - small pure URL helpers used by app code and tests.
- Create: `src/kavita-url.test.ts` - unit tests for URL normalization and validation.
- Create: `src/main.test.ts` - DOM tests for the launch UI and redirect behavior.
- Create: `src/styles.css` - minimal full-screen launch/retry styling.
- Create: `tsconfig.json` - TypeScript compiler config.
- Create: `vite.config.ts` - Vite and Vitest config.
- Create: `.gitignore` - ignores dependencies, builds, generated native output, and visual-companion state.
- Create: `.env.example` - documents the required `VITE_KAVITA_URL` variable.
- Create: `capacitor.config.ts` - Capacitor app metadata and WebView navigation allowlist.
- Generated by command: `ios/` - Capacitor iOS native project.
- Generated by command: `android/` - Capacitor Android native project.
- Modify after generation: `android/app/src/main/AndroidManifest.xml` - allows cleartext HTTP traffic for local Kavita servers.
- Modify after generation: `ios/App/App/Info.plist` - allows local HTTP Kavita servers through App Transport Security for this personal v1.

## Assumptions

- The current workspace is empty and not a git repository.
- The initial version uses a build-time Kavita URL from `VITE_KAVITA_URL` rather than a first-run settings screen.
- The Kavita URL may be HTTPS, LAN HTTP, or VPN HTTP.
- App Store / Play Store distribution is out of scope for this iteration.

- [ ] **Step 3: Create `src/kavita-url.ts`**

```ts
export type KavitaEnv = {
  readonly VITE_KAVITA_URL?: string;
};

export function normalizeKavitaUrl(rawUrl: string | undefined): string {
  const trimmedUrl = rawUrl?.trim();

  if (!trimmedUrl) {
    throw new Error('VITE_KAVITA_URL is required');
  }

  let parsedUrl: URL;

  try {
    parsedUrl = new URL(trimmedUrl);
  } catch {
    throw new Error('VITE_KAVITA_URL must be a valid URL');
  }

  if (parsedUrl.protocol !== 'http:' && parsedUrl.protocol !== 'https:') {
    throw new Error('Kavita URL must start with http:// or https://');
  }

  return trimmedUrl.replace(/\/+$/, '');
}

export function getKavitaUrl(env: KavitaEnv): string {
  return normalizeKavitaUrl(env.VITE_KAVITA_URL);
}
```

```ts
import './styles.css';
import { getKavitaUrl } from './kavita-url';

type LauncherOptions = {
  readonly kavitaUrl: string;
  readonly navigate: (url: string) => void;
};

function escapeHtml(value: string): string {
  const element = document.createElement('span');
  element.textContent = value;
  return element.innerHTML;
}

export function renderKavitaLauncher(root: HTMLElement, options: LauncherOptions): void {
  const escapedUrl = escapeHtml(options.kavitaUrl);

  root.innerHTML = `
    <section class="shell" aria-labelledby="launcher-title">
      <div class="panel">
        <h1 class="title" id="launcher-title">Opening Kavita</h1>
        <p class="message">Loading ${escapedUrl} in the app shell.</p>
        <div class="actions">
          <button class="button" type="button">Retry</button>
        </div>
      </div>
    </section>
  `;

  root.querySelector('button')?.addEventListener('click', () => {
    options.navigate(options.kavitaUrl);
  });

  options.navigate(options.kavitaUrl);
}

export function renderConfigurationError(root: HTMLElement, error: unknown): void {
  const message = error instanceof Error ? error.message : 'Unknown configuration error';

  root.innerHTML = `
    <section class="shell" aria-labelledby="error-title">
      <div class="panel">
        <h1 class="title" id="error-title">Kavita URL Missing</h1>
        <p class="message">${escapeHtml(message)}</p>
      </div>
    </section>
  `;
}

const app = document.querySelector<HTMLDivElement>('#app');

if (!app) {
  throw new Error('App root #app was not found');
}

try {
  renderKavitaLauncher(app, {
    kavitaUrl: getKavitaUrl(import.meta.env),
    navigate: (url) => {
      window.location.replace(url);
    },
  });
} catch (error) {
  renderConfigurationError(app, error);
}
```
